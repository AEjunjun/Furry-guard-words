# furry-guard

简体中文 | [English](README.md)

Furry 文化歧视 / 引战话术屏蔽词库

## 项目简介

轻量级、独立的 Furry 专项屏蔽词扩展包。不含任何代码实现——这是纯词表包，可配合主过滤系统使用，也可单独使用。

## 词表说明

| 文件 | 说明 |
|------|------|
| `toxic.txt` | 硬屏蔽（明确辱骂 / 性化内容 / 兽交） |
| `dogwhistle.txt` | 软标记（引战狗哨话术） |
| `slur_en.txt` | 英文 slur（歧视性辱骂词） |
| `allowlist.txt` | 白名单正常词（防止误杀正常讨论） |
| `regex.txt` | 正则规则（预留） |

## 参与贡献

欢迎补充词表！直接提 PR 往对应 txt 里加词即可

格式规范：
- 一行一个词
- `#` 开头为注释
- 空行自动忽略
